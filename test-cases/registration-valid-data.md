# Регистрация с валидными данными

**ID:** TC-001  
**Приоритет:** High  
**Тип:** Позитивный

## Предусловия

Пользователь не зарегистрирован в системе.

## Тестовые данные

Email: `test@example.com`  
Пароль: `Qwerty123!`

## Шаги

1. Открыть страницу регистрации.
2. Ввести валидный email.
3. Ввести валидный пароль.
4. Подтвердить пароль.
5. Нажать кнопку «Зарегистрироваться».

## Ожидаемый результат

Пользователь успешно зарегистрирован и получает доступ к авторизованной части приложения.
