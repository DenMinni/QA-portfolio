# Регистрация с некорректным паролем

**ID:** TC-002  
**Приоритет:** High  
**Тип:** Негативный

## Предусловия

Пользователь не зарегистрирован в системе.

## Тестовые данные

Email: `test@example.com`  
Пароль: `123`

## Шаги

1. Открыть страницу регистрации.
2. Ввести валидный email.
3. Ввести пароль, не соответствующий требованиям системы.
4. Нажать кнопку «Зарегистрироваться».

## Ожидаемый результат

Регистрация не выполняется. Пользователь видит понятное сообщение об ошибке с указанием требований к паролю.
