# Проверка POST-запроса создания пользователя

**Метод:** POST  
**Endpoint:** `/api/users`  
**Приоритет:** High

## Цель

Проверить создание нового пользователя через REST API.

## Тело запроса

{
  "name": "Иван",
  "email": "ivan@example.com"
}

## Ожидаемый результат

- HTTP-код ответа — `201 Created`.
- Пользователь успешно создан.
- В ответе присутствует идентификатор нового пользователя.
- Данные пользователя соответствуют отправленным.
- Созданного пользователя можно получить отдельным GET-запросом.

## Негативные проверки

- Пустое обязательное поле `name`.
- Пустое обязательное поле `email`.
- Некорректный формат email.
- Email уже существует.
- Пустое тело запроса.
- Некорректный JSON.
