# Проверка GET-запроса получения пользователя

**Метод:** GET  
**Endpoint:** `/api/users/{id}`  
**Приоритет:** High

## Цель

Проверить получение данных существующего пользователя через REST API.

## Предусловия

Пользователь с указанным `id` существует в системе.

## Запрос

GET /api/users/123

## Ожидаемый результат

- HTTP-код ответа — `200 OK`.
- Ответ содержит данные пользователя.
- Формат ответа — JSON.
- Обязательные поля присутствуют.
- Значение `id` в ответе соответствует запрошенному пользователю.

## Негативные проверки

- Несуществующий `id` → `404 Not Found`.
- Некорректный формат `id` → корректная ошибка валидации.
- Отсутствие авторизации → соответствующий код ошибки.
- Проверка поведения при недоступности сервиса.
