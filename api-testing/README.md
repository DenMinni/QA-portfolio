# API-тестирование

Практика тестирования REST API с использованием Postman.

## Что проверено

- GET — получение списка ресурсов;
- GET — получение конкретного ресурса;
- обработка 404 Not Found;
- POST — создание ресурса;
- PUT — обновление ресурса;
- DELETE — удаление ресурса;
- проверка HTTP status codes;
- проверка JSON-ответов;
- проверка структуры response body;
- проверка соответствия данных запроса и ответа;
- автоматизированные проверки в Postman.

## Postman Collection

В репозитории находится коллекция:

`QA Portfolio — REST API.postman_collection.json`

Коллекция содержит позитивные и негативные сценарии API-тестирования.
